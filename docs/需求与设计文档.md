# 校园 OA 前端需求与设计文档

文档依据当前前端实现整理，覆盖信息架构、功能范围和便当盒视觉规范。文中「已实现」指页面与交互已经存在；「占位」指入口已有、业务尚未接入；「展示数据」指界面写死或仅在本地切换、未与后端统计对齐。

- 产品名称：校园 OA
- 前端工程：camp-web
- 技术栈：Vue 3、Vue Router 4、Vite 5
- 页面语言：简体中文
- 字体：Plus Jakarta Sans
- 图标：Lucide（iconify-icon）
- 样式：原生 CSS，无 Tailwind。全局令牌在 `src/style.css`，管理页网格在 `src/styles/bento-admin.css`

## 1. 产品目标

校园 OA 给教职工和学生提供统一办公入口，完成学籍与组织信息、教学、考试、权限、公告和来访登记的日常维护。界面采用便当盒布局：卡片大小有层次，间隙、圆角和悬停反馈保持同一套。

设计优先级：

1. 风格一致，其次才是单页创意。
2. 禁止项高于风格建议。不使用紫到蓝的渐变，不把玻璃态当作默认表面，不用单侧粗色条装饰，不在卡片里再套卡片。
3. 管理数据放在大卡片里的表格中，不把每一行记录拆成小卡片。

## 2. 用户与权限

界面按身份区分登录，登录后的菜单目前对已登录用户完整展示，不按角色隐藏入口。角色名称来自 `userType`：1 学生、2 教工、3 管理员。

| 身份 | 登录方式 | 说明 |
| --- | --- | --- |
| 学生 | 学号 + 密码 | 首次登录需核验姓名并激活密码 |
| 教工 | 工号 + 密码 | 同上 |
| 家长 / 访客 | 未开放 | 登录页按钮禁用 |

开发环境 `SKIP_LOGIN_FOR_DEV = true` 时，访问 `/` 与 `/login` 会写入模拟管理员并进入 `/home/`。上线前必须关闭。

认证数据存在 `localStorage` 的 `token` 与 `userInfo`。`/home` 及其子路由需要登录；已登录再访问登录页则回到首页。退出登录会清除这两项并回到登录页，退出前需确认。

## 4. 功能需求

### 4.1 登录

- 支持账号密码和人脸识别两种方式切换。
- 账号密码登录先选身份，再输入学号或工号、密码。
- 首次登录进入姓名核验，通过后打开激活密码对话框。
- 人脸登录调用摄像头，提示光线与正对镜头，可停止验证。
- 登录页右侧是表单大卡，左侧是深色介绍卡和两张浅色说明卡。家长入口在说明卡中标明未开放。

### 4.2 找回密码

- 学生使用六要素：学号、真实姓名、身份证号、应急联系人姓名、电话、关系。
- 教工使用工号、姓名、手机号和验证码。验证码发送后有倒计时。
- 成功后提示新密码为身份证号后 6 位，并引导前往登录、随后修改密码。
- 页面结构与登录页相同：深色说明、浅色提示、宽表单。

### 4.3 首页概览

首页是 4 列便当盒，卡片尺寸必须不同。

| 卡片 | 跨列 | 内容 | 数据来源 |
| --- | --- | --- | --- |
| 学生总数 | 2 | 数字与橙色图标，浅橙底 | 展示数据 2,482 |
| 进行中课程 | 1 | 数字 | 展示数据 142 |
| 最新公告 | 1 | 数字 | 展示数据 08 |
| 个人待办 | 2 | 列表，可点切换完成，显示未完成数量 | 本地列表 |
| 日历 | 2 | 月历，可切换月份并选中日期 | 本地日期 |
| 天气 | 3 | 地点、天气、温度、湿度、风速；失败时可更新位置 | 定位优先，否则北京 |
| 即将安排 | 1 | 数字 | 展示数据 14 |

桌面端第一行是宽指标加两张小指标，第二行是待办与日历，第三行是宽天气加小指标。宽度不超过 1100px 时改为 2 列，不超过 720px 时改为 1 列。1440×820 左右应能在一屏内看完主要卡片。

### 4.4 管理列表

除考勤、个人信息、修改密码和占位页外，管理页共用同一骨架：

1. 标题卡：页面名称和主操作（新增、发布）。
2. 筛选卡：与标题并排。条件变化或回车后重新查询，并提供搜索按钮。
3. 表格大卡：横跨整行。列较多时在卡片内横向滚动，页面本身不出现横向滚动条。
4. 分页：上一页、下一页，以及当前页、总页数、总条数。
5. 弹窗：新增和编辑。必填项标红星。取消关闭，保存后关闭并刷新列表。
6. 删除前使用确认框。成功和失败用 Toast 提示。

各页主操作：

| 页面 | 主操作 | 行内操作要点 |
| --- | --- | --- |
| 学生信息 | 新增学生 | 编辑、删除。状态含休学、在读、毕业、退学。编辑时学号只读 |
| 应急联系人 | 新增应急联系人 | 编辑、删除、设为主要联系人 |
| 年级 | 列表维护 | 按现有页内操作 |
| 班级 | 新增班级 | 编辑、删除 |
| 教师班级 | 新增关联 | 需先选定教师 |
| 年级管理员 | 新增关联 | 需先选定管理员 |
| 科目 | 新增科目 | 编辑、删除 |
| 班级授课 | 添加科目 | 从班级上下文进入，可返回。支持添加与编辑授课关系 |
| 考试安排 | 新增考试安排 | 可按年级、考试类型、是否公开、状态筛选 |
| 考试成绩 | 新增成绩 | 编辑、删除 |
| 用户 | 新增用户 | 编辑、删除、启用或停用 |
| 角色权限 | 新增角色 | 编辑、删除、分配权限（权限树） |
| 数据权限 | 新增权限配置 | 编辑、删除 |
| 校园公告 | 发布公告 | 编辑、删除、置顶、撤回。状态含已发布、草稿、已撤回 |
| 来访登记 | 新增来访登记 | 编辑、删除、批准、拒绝、入校、离校 |

### 4.5 考勤

考勤页不用「标题 + 筛选」的双列标题行，而是五块卡片：

1. 标题卡「考勤管理」。
2. 标签卡：班级每日考勤汇总、学生异常考勤记录。选中项为锌黑底白字。
3. 操作卡：新增考勤汇总或新增异常记录。
4. 筛选卡：年级、班级、日期等。
5. 表格大卡。

两个标签的内容互斥显示，隐藏的一组不占网格位置。

### 4.6 个人中心

- 个人信息：标题通栏。读取成功时，基本信息占 3 列，编辑和修改密码占 1 列。可编辑真实姓名和头像地址。读取失败时显示说明卡，不用空白页。
- 修改密码：标题卡与表单卡并排。字段为旧密码、新密码、确认新密码。新密码至少 6 位。提供取消和确认修改。

### 4.7 占位页

导入导出和统计报表使用占位页：一块深色大卡说明功能尚未接入，并提供返回首页；旁边三张浅色小卡说明后续不会把未完成能力堆进同一张卡片。

## 5. 交互需求

- 可点击卡片悬停时上移 4px 并放大到 1.01，阴影由紧凑变为 `0 8px 30px rgba(0,0,0,0.08)`。过渡 200–300ms，缓动 `ease-out`。
- 卡片内图标在卡片悬停时放大。
- 按钮按下时缩放到 0.95 或 0.98。
- 输入框聚焦时边框变为 `#2563eb`，并带 3px、20% 不透明度的蓝色光环。过渡要平滑。
- 分组菜单一次只展开一个。当前页所在分组自动打开，当前项有选中底色。
- 弹窗点遮罩或关闭按钮可关闭。表单提交使用按钮的主次区分，主按钮在右。
- 删除、退出等破坏性动作先确认。
- `prefers-reduced-motion: reduce` 时关闭位移动画和时长过渡。
- 窄屏侧栏不占用内容宽度。抽屉打开时有半透明遮罩。

## 6. 视觉规范

风格名称：便当盒（Bento Grid）。灵感是日式便当的分隔：模块独立、尺寸分出主次、间隙统一、每张卡片像一块小组件。

### 6.1 禁止

- 所有卡片一样大。
- 网格间隙混用。页面网格只用 16px。
- 直角，以及小于 12px 的圆角。
- 紫到蓝渐变。彩色大面积只使用浅橙、浅绿等浅底，文字保持深色。
- 玻璃拟态作为默认表面。
- 卡片左侧或右侧的强调色粗边。
- 卡片套卡片。表格、表单、标签都放在卡片内部，不再包一层卡片。
- 每个标题上方放极小的全大写眉题。
- 渐变文字、弹跳或弹性缓动。
- 仅用颜色表示状态。状态必须同时有文字。
- Inter、Roboto、Geist 作为界面字体。

### 6.2 颜色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#fafafa` | 工作台底色 |
| 卡片背景 | `#ffffff` | 默认表面 |
| 主文字 | `#18181b` | 标题、数字、主按钮底 |
| 次文字 | `#52525b`、`#71717a` | 说明、标签、辅助信息 |
| 弱文字 | `#a1a1aa` | 占位、分组小标题 |
| 边框 | `#f4f4f5` 卡片，`#e4e4e7` 输入框 | 分隔 |
| 焦点 | `#2563eb`，光环 `rgba(37,99,235,0.2)` | 输入与键盘焦点 |
| 浅橙 | `#fff7ed` / 边 `#ffedd5` | 首页主指标、暖色说明卡 |
| 浅绿 | `#f0fdf4` / 边 `#dcfce7` | 天气、成功向说明卡 |
| 图标橙 | 底 `#ffedd5`，字 `#c2410c` | 用户、待办类图标 |
| 图标蓝 | 底 `#eff6ff`，字 `#1d4ed8` | 课程、日历类图标 |
| 图标绿 | 底 `#f0fdf4`，字 `#15803d` | 天气、日程类图标 |
| 成功文字 | `#166534`，底 `#f0fdf4` | 启用、已发布、已批准 |
| 危险文字 | `#991b1b` 或 `#b91c1c`，底 `#fef2f2` | 停用、拒绝、删除 |
| 警告文字 | `#9a3412`，底 `#fff7ed` | 草稿、待处理 |
| 深色卡 | `#18181b`，字 `#ffffff`，说明 `#e4e4e7` | 登录介绍、占位主卡 |
| 遮罩 | `rgba(24,24,27,0.4)` | 弹窗与移动端抽屉 |

主按钮是锌黑底白字，悬停 `#27272a`。次按钮、分页、返回是 `#fafafa` 底、`#e4e4e7` 边、`#18181b` 字。深色卡片上的主按钮反色为白底黑字，保证能看清。

白字只放在 `#18181b`、`#15803d`、`#b91c1c` 这类深底上。浅色卡片上的正文保持锌色，对比度按 WCAG AA 正文 4.5:1 控制。

### 6.3 字体与字号

字体栈：`Plus Jakarta Sans`，然后是系统无衬线字体。字重只用 400、500、600、700。

| 用途 | 规格 |
| --- | --- |
| 顶栏问候 | 1.5rem / 600，窄屏 1.25rem |
| 页面标题 | 1.25rem / 600，字距 -0.02em |
| 首页大数字 | 较标题更重，字距收紧 |
| 卡片标题 | 约 1.125rem / 600 |
| 正文、表格、按钮 | 0.875rem |
| 分组名、状态胶囊 | 0.75rem / 600 |
| 登录与占位主标题 | 1.875rem / 600，白字 |

中文正文行宽控制在大约 65–75 个字符以内。说明文字放在卡片内，不拉成通栏长句。

### 6.4 形状、阴影、间距

| 令牌 | 值 |
| --- | --- |
| 卡片圆角 | 16px（1rem） |
| 按钮、输入、菜单项圆角 | 12px（0.75rem） |
| 状态胶囊 | 全圆角 |
| 校徽 | 36×36px，圆角 12px，底 `#18181b` |
| 默认阴影 | `0 1px 2px rgba(0,0,0,0.05)` |
| 悬停阴影 | `0 8px 30px rgba(0,0,0,0.08)` |
| 页面网格间隙 | 16px |
| 卡片内间隙 | 12px |
| 侧栏宽度 | 220px |
| 管理页内边距 | 16px 24px 24px |
| 断点 | 1100px 改为 2 列；720px 管理页改为 1 列；768px 侧栏改抽屉 |

侧栏校徽左缘与菜单图标左缘对齐，目前都在距侧栏左缘 24px 处。分组小标题、子菜单和底部用户头像沿同一条左边线排布。子菜单相对父级文字缩进，不另加竖线。

## 7. 组件规范

### 7.1 侧栏

- 固定在视口左侧，高度 100vh，白底，右边线 `#f4f4f5`。
- 顶部是校徽加「校园OA」，没有折叠按钮。
- 其下是「功能菜单」和分组列表。选中项底 `#f4f4f5`，字色 `#18181b`。
- 悬停时图标放大到 1.1。按下时菜单项缩放到 0.98。
- 底部用户卡：头像取姓名后两字，展示姓名和身份，并提供退出。
- 窄屏宽度为 `min(18rem, 86vw)`，关闭时 `translateX(-105%)`。

### 7.2 顶栏

白底，底边 `#f4f4f5`。左侧问候和副标题，右侧搜索、通知、退出。搜索框浅底、12px 圆角、聚焦蓝环。通知按钮 40×40px。退出是锌黑胶囊按钮。窄屏顶栏改为上下两行，搜索拉满。

### 7.3 首页卡片

白底、16px 圆角、1px `#f4f4f5` 边、默认小阴影。主指标用浅橙，天气用浅绿。图标放在 浅色圆角块里。悬停整卡上浮，图标单独放大。

### 7.4 管理页卡片

标题、筛选、表格、标签、操作、资料、表单都使用同一套卡片表面和悬停。表格表头底 `#fafafa`，表头字 0.75rem，单元格 0.875rem。行悬停仅改变行背景，不把整行做成新卡片。

### 7.5 按钮

| 类型 | 外观 | 场景 |
| --- | --- | --- |
| 主按钮 | 黑底白字，12px 圆角，字重 500 | 新增、保存、搜索、登录 |
| 次按钮 | 浅底深字，浅灰边 | 取消、返回、分页、修改密码链接 |
| 行内按钮 | 更小的浅底按钮 | 编辑为深色字，删除和拒绝为红色字，批准和启用为绿色字 |
| 按下 | `scale(0.95)` | 所有按钮 |

### 7.6 表单

输入、下拉、多行文本：宽 100%，内边距 8px 12px，背景 `#fafafa`，边框 `#e4e4e7`，圆角 12px。只读字段背景 `#f4f4f5`。必填星号 `#b91c1c`。字段提示 0.75rem、`#71717a`。错误提示块为浅红底和深红字，同样 12px 圆角。复选框保持 16px，不被拉成通栏。

### 7.7 弹窗与提示

- 遮罩覆盖全屏。内容卡最大宽约 40rem，大表单约 60rem，最高约 90vh，16px 圆角。
- 标题栏与内容区用 `#f4f4f5` 分隔。关闭按钮是 36px 浅底方块。
- Toast 固定在右上，16px 圆角。成功 `#15803d`，失败 `#b91c1c`，信息 `#18181b`，文字为白色。

### 7.8 状态胶囊

启用、已发布、已批准、已入校、毕业使用绿色胶囊。停用、已撤回、已拒绝使用红色胶囊。草稿、待处理、已离校、主要联系人使用橙色胶囊。胶囊内必须有文字。

## 8. 响应与无障碍

- 桌面、1100px 平板、768px 手机三档都要能完成打开菜单、筛选、翻页和弹窗。
- 页面不出现横向溢出。宽表格只在表格卡片内滚动。
- 交互元素提供可访问名称：菜单按钮、月份切换、关闭菜单。
- 焦点用蓝色描边，不靠颜色单独传达选中。
- 减弱动态偏好开启时，取消上浮和缩放。

## 9. 非功能需求

- 本地开发：`npm run dev`，默认 Vite 端口，当前调试使用 `http://127.0.0.1:3000/`。
- 构建：`npm run build`，产物目录 `dist`。
- 接口基址：`VITE_API_BASE_URL`，缺省 `http://localhost:8080`。
- 浏览器需支持 CSS Grid、`iconify-icon` 和可选的摄像头（人脸登录）。
- 开发跳过登录仅用于联调，不能进入生产配置。

## 10. 与实现的差异

这些差异应在后续需求里单独立项，不要当成已经完成的业务能力：

- 首页四个数字和待办列表是展示数据，待办完成状态只留在当前页面。
- 顶栏搜索和通知没有业务行为。
- 导入导出、统计报表只有占位布局。
- 菜单未按学生、教工、管理员裁剪。
- 家长 / 访客登录未开放。

## 11. 设计自检

交付新页面时逐条核对：

- 使用 CSS Grid，桌面 4 列，间隙 16px。
- 至少有一张明显更大的卡片，不能全部等宽等高。
- 卡片圆角 16px，控件圆角 12px。
- 悬停上浮加轻微放大，图标单独响应，按下有缩放。
- 没有紫蓝渐变、玻璃默认表面、左侧色条、嵌套卡片。
- 浅底上使用深色文字；状态有文字标签。
- 窄屏改为单列，侧栏改为抽屉。
- 减弱动态偏好下没有位移。
